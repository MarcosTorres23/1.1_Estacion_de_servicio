⛽ Estación de Servicio – Sistema de gestión

Aplicación de escritorio desarrollada en C# con Windows Forms para la gestión integral de una estación de servicio: clientes, empleados, productos, proveedores, stock, compras y ventas.

Proyecto académico desarrollado en equipo para la carrera de Ingeniería Informática (Universidad Americana).

Módulos
Inicio: pantalla de acceso al sistema.
Home: menú principal de navegación entre módulos.
Clientes: registro y administración de clientes.
Empleados: gestión del personal de la estación.
Productos: catálogo de productos y combustibles.
Proveedores: registro de proveedores.
Stock: control de existencias.
Compras: registro de compras a proveedores.
Ventas: registro de ventas a clientes.
Tecnologías
Lenguaje: C#
Interfaz: Windows Forms (.NET Framework)
IDE: Visual Studio
